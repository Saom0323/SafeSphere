About SafeSphere

Smart Emergency Response System

📖 Project Overview

SafeSphere is a web-based emergency response system developed using Django and Bootstrap. It allows users to report emergencies, access AI-based safety guidance, contact emergency services, and manage emergency reports efficiently.

✨ Main Features

  • User Registration & Login
  • Emergency Report System
  • AI Safety Assistant
  • Emergency Contact Buttons
  • User Profile
  • Admin Dashboard
  • Emergency Report History

🛠 Technologies Used

Python
Django
Bootstrap 5
SQLite

🎯 Project Goal

The goal of SafeSphere is to provide a fast, secure, and intelligent emergency response platform that helps people report emergencies and receive immediate assistance.
